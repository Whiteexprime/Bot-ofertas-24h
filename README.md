# BotOfertas — site institucional

Site estático responsivo, pronto para GitHub Pages. Não exige instalação ou processo de build.

A página usa a logomarca horizontal oficial em `assets/logo-botofertas.png`, com favicons dedicados derivados do mascote (`favicon-32.png` e `favicon-180.png`). A ordem pública é: apresentação, funcionalidades, grupos do Telegram, acesso ao bot privado, WhatsApp, redes sociais e rodapé.

## Publicar
1. Extraia o ZIP.
2. Envie o conteúdo da pasta `BotOfertas_SITE_PROFISSIONAL` para a raiz do repositório.
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`.
5. Salve e aguarde a publicação.

## Observações
- O site informa que as pesquisas do bot são limitadas por dia.
