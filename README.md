# BotOfertas

Site institucional do BotOfertas, preparado para publicação no GitHub Pages.

## Publicar no GitHub Pages
1. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch principal (`main`) e a pasta `/ (root)`, depois salve.
5. Aguarde a publicação e acesse o endereço informado pelo GitHub.

O site é estático: não precisa de instalação, servidor ou processo de build. A página inicial é `index.html`.
