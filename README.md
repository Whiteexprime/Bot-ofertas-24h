# BotOfertas — Site

Site público do BotOfertas, feito para GitHub Pages.

## Estrutura
- Início: comunidades e entrada para as ofertas
- Ofertas: área de oportunidades
- Categorias: navegação por tipo de produto
- Cupons: como os descontos aparecem
- Comunidade: links dos canais
- Como funciona: explicação simples do BotOfertas
- Ajuda e Dúvidas: suporte ao visitante

## Som
O site possui efeitos sonoros leves gerados pelo próprio navegador, sem arquivos externos. O botão no canto inferior permite ligar/desligar. A preferência fica salva no navegador.

## GitHub Pages
Envie os arquivos deste diretório para um repositório e ative Pages usando a branch principal e a pasta raiz.
